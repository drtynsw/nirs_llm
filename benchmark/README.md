# Benchmark

Тестовый набор запросов для оценки поиска. Заполняется к КТ2.

## Формат `queries.jsonl`

Одна строка — один запрос:

```json
{"id": "q17", "query": "работодатель говорит, что первый месяц стажировка и платить не будет", "topic": "испытательный срок", "style": "бытовой", "relevant": ["tk_70", "tk_71", "tk_57"]}
```

- `relevant` — `doc_id` из `data/corpus.jsonl`, не меньше трёх.
- `topic` — для проверки равномерного покрытия тем.
- `style` — `юридический` или `бытовой`: метрики считаем отдельно, чтобы увидеть
  разрыв словаря (`spec/tech/rag.md`).

## Черновик запросов

Формулировки готовы, разметка `relevant` — на КТ2. Файл: `queries_draft.jsonl`.
Разметку делаем после загрузки актуальной редакции законов: `doc_id` фрагментов
могут измениться.

## Запуск (КТ2)

```bash
python -m benchmark.run --k 5 10
```

Выводит Recall@5, Recall@10, MRR (всего и по `style`) и сохраняет отчёт в `benchmark/results/`.
