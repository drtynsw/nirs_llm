# Администрирование и аналитика

## Роль администратора

- Один общий секрет `ADMIN_TOKEN` (переменная окружения или `.env`).
- Не задан — при старте генерируется случайный токен (`secrets.token_urlsafe`)
  и печатается в консоль; после перезапуска он другой.
- Проверка — `hmac.compare_digest`, заголовок `Authorization: Bearer <токен>`.
- Страница `/admin` хранит токен в `sessionStorage`: закрыл вкладку — вышел.
- Ограничение: нет защиты от перебора и HTTPS — сервер рассчитан на локальный
  запуск и демонстрацию. Для публичного размещения нужен обратный прокси с TLS.

## Что храним

Таблица `events` в `data/analytics.sqlite3` (путь меняется `ANALYTICS_DB`):

| Поле | Тип | Смысл |
| --- | --- | --- |
| ts | TEXT | время запроса, ISO 8601, UTC |
| day | TEXT | дата `YYYY-MM-DD` (UTC) для группировки |
| age_group | TEXT | группа возраста или NULL |
| topic | TEXT | тема по ключевым словам вопроса |
| top_k | INTEGER | запрошенное число статей |
| n_docs | INTEGER | сколько статей найдено |
| top_docs | TEXT | JSON `[[doc_id, citation], …]` — первые 3 статьи |
| took_ms | REAL | время обработки |
| no_answer | INTEGER | 1, если статей не нашлось (С4) |

**Не храним:** текст вопроса, точный возраст, IP, User-Agent, cookie. Тема
вычисляется в момент запроса, сам текст не записывается.

## Темы

Первое совпадение по корням слов (регистр не важен), иначе «Другое»:

| Тема | Корни |
| --- | --- |
| Самозанятость | самозан, налог, нпд |
| Договор подряда и услуг | подряд, услуг, гпх, фриланс, заказчик |
| Испытательный срок | испыт, стажир |
| Увольнение | увол, расторж, сокращ |
| Отпуска и учёба | отпуск, сесси, учебн, каникул |
| Оплата труда | зарплат, заработн, плат, деньг, задерж, преми |
| Рабочее время | час, смен, график, ноч, выходн, переработ, сверхуроч |
| Оформление | оформ, договор, устро, официал, трудоустр |

## Возрастные группы

`до 14`, `14–15`, `16–17` — границы ст. 63 и гл. 42 ТК РФ; `18–23` — основная
аудитория; `24+`. Точный возраст в аналитику не попадает.
