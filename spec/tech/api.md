# API

Все ответы — JSON в UTF-8. Ошибки: `{"error": "текст"}` с кодом 4xx.

## POST /api/ask

Запрос:

```json
{"question": "Сколько длится испытательный срок?", "top_k": 5}
```

| Поле | Тип | Правило |
| --- | --- | --- |
| question | строка | обязательно, 1–500 символов после обрезки пробелов |
| top_k | целое | необязательно, по умолчанию 5, приводится к 1–10 |

Ответ 200:

```json
{
  "question": "Сколько длится испытательный срок?",
  "answer": "…",
  "mode": "prototype",
  "documents": [
    {"doc_id": "tk_70", "citation": "ст. 70 ТК РФ", "law": "ТК РФ",
     "article": "70", "title": "Испытание при приеме на работу",
     "score": 11.0, "snippet": "…"}
  ],
  "took_ms": 12.4
}
```

- `documents` отсортированы по убыванию `score`, длина ≤ `top_k`, может быть пустым.
- `answer` всегда заканчивается оговоркой «…не юридическая консультация» (кроме случая С4).
- `mode`: `"prototype"` на КТ1, `"rag"` после подключения BM25 и LLM.

Ошибки 400: пустой вопрос, длинный вопрос, нечисловой `top_k`, некорректный JSON.
