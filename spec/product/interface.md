# Интерфейс

Одна страница, без входа и без навигации. Ширина контента 820 px; на телефоне —
одна колонка, кнопка под полем ввода (основной сценарий — с телефона).
Светлая и тёмная тема по системной настройке.

Скриншот: [docs/prototype.png](../../docs/prototype.png).

## Блоки сверху вниз

| Блок | Содержимое | Поведение |
| --- | --- | --- |
| Шапка | «Трудовое право для студентов», одна строка о назначении | — |
| Поле вопроса | Многострочное, до 500 символов, подсказка-пример | Enter — отправить, Shift+Enter — новая строка |
| Кнопка «Спросить» | — | Во время запроса: «Ищу…», заблокирована |
| Примеры | 4 частых вопроса: увольнение, испытательный срок, ночная работа, самозанятость | Клик подставляет и отправляет |
| Число статей | 3 / 5 / 10, по умолчанию 5 | Передаётся как `top_k` |
| Карточка «Ответ» | Текст ответа + оговорка «не юридическая консультация»; метка «прототип», пока работает заглушка | — |
| Карточка «Найденные статьи» | Нумерованный список: плашка «ст. N ТК РФ», название статьи, оценка, фрагмент; время поиска | — |
| Подвал | Оговорка, куда обращаться в спорной ситуации; размер корпуса | Из `GET /api/sources` |

## Решения

- Ссылка на статью — плашкой перед названием: её студент будет показывать работодателю.
- Оговорка в ответе и в подвале: сервис отвечает по тексту закона, а ошибка в
  юридическом вопросе может дорого стоить пользователю.
- Фрагмент вырезается вокруг первого слова запроса, а не с начала статьи.
- Оценку показываем, чтобы на защите было видно ранжирование; для пользователей скроем на КТ3.
- Без фреймворков: один HTML-файл и чистый JS, запуск без `npm`.
