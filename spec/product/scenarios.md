# Сценарии

## С1. Основной: ситуация → статьи → ответ

**Кто:** студентка устроилась администратором в кафе, ей сказали, что первый месяц —
«испытательный» и за него заплатят меньше или не заплатят вовсе.

1. Открывает приложение с телефона, видит поле вопроса и примеры.
2. Пишет «Мне не хотят платить за испытательный срок, это законно?» и нажимает
   «Спросить» (или Enter).
3. Кнопка меняется на «Ищу…» и блокируется до ответа.
4. Видит карточку «Ответ»: 2–4 предложения простым языком со ссылками
   («по ст. 70 ТК РФ на испытании действуют все нормы трудового права…»)
   и строку «Это справка по тексту закона, а не юридическая консультация».
5. Ниже — «Найденные статьи»: «ст. 70 ТК РФ» + название, фрагмент текста, оценка.
   По умолчанию 5 статей.
6. Открывает нужную статью и показывает работодателю.

**Готово, когда:** в выдаче есть ст. 70 ТК РФ, и ответ ссылается только на
статьи из выдачи.

## С2. Быстрый старт с примера

Студент не знает, как сформулировать, и нажимает на пример под полем ввода.
Вопрос подставляется и сразу отправляется. Дальше как в С1.

## С3. Больше или меньше статей

Студент выбирает «Показывать статей: 3 / 5 / 10». Следующий запрос возвращает
столько статей. Сервер ограничивает значение диапазоном 1–10.

## С4. Вопрос не про трудовое право

«Как вернуть деньги за курсы?», «Какая погода в Москве?». Приложение показывает
«В загруженных законах не нашлось подходящих статей. Попробуйте описать
ситуацию другими словами». На КТ2: если оценка лучшей статьи ниже порога,
LLM не вызывается.

## С5. Ошибки ввода

| Ситуация | Поведение |
| --- | --- |
| Пустой вопрос | Кнопка не отправляет; API отвечает 400 «Пустой вопрос» |
| Вопрос > 500 символов | Поле не даёт ввести больше; API отвечает 400 |
| Сервер недоступен / ошибка LLM | Красная карточка с текстом ошибки, введённый вопрос сохраняется |

## Примеры реальных вопросов (основа для benchmark)

| Ситуация | Ожидаемые статьи |
| --- | --- |
| Не оформили официально, работаю «на словах» | ст. 16, 67 ТК РФ |
| Сколько часов можно работать, если учусь | ст. 92, 93, 282–284 ТК РФ |
| Не хотят платить за испытательный срок | ст. 70, 71 ТК РФ |
| Хочу уволиться, а не отпускают | ст. 80 ТК РФ |
| Задерживают зарплату | ст. 136, 142, 236 ТК РФ |
| Положен ли отпуск на сессию | ст. 173–177 ТК РФ |
| Работаю по договору услуг — какие у меня права | ст. 779–783 ГК РФ, ст. 11, 15 ТК РФ |
| Как стать самозанятым и сколько платить | 422-ФЗ, ст. 4, 5, 10 |

## Состояние на КТ1

С1–С5 проходят в прототипе. Отличие от целевого поведения: ответ — шаблон-заглушка,
статьи ищутся по совпадению слов без BM25 и лемматизации.
