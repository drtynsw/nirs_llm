# История изменений

## КТ1 — документация и интерфейс (октябрь 2026)

- Выбрана тема: консультант по трудовому праву для студентов на подработке.
- Собран корпус: ТК РФ, ГК РФ (гл. 37 § 1, гл. 39), 422-ФЗ — 473 статьи,
  513 документов после деления длинных статей (`scripts/fetch_laws.py`,
  `scripts/build_corpus.py`).
- Известное ограничение: в открытом наборе данных ранние редакции законов.
  Подготовлен `scripts/parse_law_text.py` для загрузки актуальной редакции на КТ2.
- Написаны спецификации: продукт, сценарии, интерфейс, архитектура, API, RAG/BM25, проверка.
- Сделан прототип: веб-интерфейс + `POST /api/ask` со стабильным контрактом.
  Поиск и ответ — заглушки, интерфейс показывает реальные статьи корпуса.
- Добавлены тесты контракта API (7 тестов).
- Черновик benchmark: 34 запроса по 8 темам, половина — бытовыми словами.
- Распределены роли в команде, план работ до КТ3 — `docs/team.md`.
